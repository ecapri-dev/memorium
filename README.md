# Memorium

Aplicación donde una persona deja preparado lo que su familia debe recibir cuando muera: las llaves para acceder a su dinero digital, más cartas, fotos y documentos. Todo cifrado en una cápsula que solo se abre cuando el sistema confirma el fallecimiento.

Proyecto de Ingeniería de Software I (SIS3407), Universidad Anáhuac Querétaro.
Autor: Emiliano Cabañas Prieto.
